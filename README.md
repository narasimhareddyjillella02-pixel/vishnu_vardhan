# To-Do List Application

A simple, lightweight to-do list app built with HTML, CSS, and JavaScript.

## Features

✅ **Add Tasks** - Simply type a task and click "Add" or press Enter  
✅ **Mark Complete** - Check off tasks when you're done  
✅ **Delete Tasks** - Remove individual tasks  
✅ **Filter View** - View All, Active, or Completed tasks  
✅ **Clear Completed** - Remove all completed tasks at once  
✅ **Local Storage** - Tasks persist even after closing the browser  
✅ **Responsive Design** - Works on desktop and mobile devices  

## Files

- `index.html` - Main HTML structure
- `style.css` - Styling and layout
- `script.js` - Functionality and logic

## How to Use

1. Open `index.html` in your web browser
2. Type a task in the input field
3. Click "Add" or press Enter to add the task
4. Click the checkbox to mark tasks as complete
5. Click "Delete" to remove a task
6. Use the filter buttons to view different task statuses
7. Click "Clear Completed" to remove all finished tasks

## Data Persistence

All tasks are automatically saved to your browser's local storage, so they'll be there when you come back!
